Cómo funciona ahora: un cron interno en el backend consulta la API del Albion Data Project cada hora y guarda los precios en Supabase. Esta página solo lee lo que el backend ya tiene guardado — el botón "Traer últimos precios" fuerza una actualización manual si no quieres esperar al cron.
